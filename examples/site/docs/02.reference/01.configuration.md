# Configuration

Markupress needs no configuration: folders, front matter and files in `public/` describe the site. `markupress.config.json` sets the title, the base path, extra top navigation links and the edit link.

## Navigation

Each top-level folder with an index page is a section in the top navigation. `nav` adds links after them.

## Sidebar

Each top-level folder is a section with its own sidebar.

### Groups

A folder below a section is a collapsible group.

## Footer

`docs/_footer.md` holds the footer's link columns and its copyright line.

## Edit link

`editLink` is a URL ending in `/`. Each page links to that URL followed by its file's path, and shows the date its file last changed in git.
