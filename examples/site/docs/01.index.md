# Markupress

Build versioned documentation from Markdown, with native HTML Next components and a Looma theme.

![](/logo.svg)

[Write your first page](01.guide/01.authoring.md) [Configuration](02.reference/01.configuration.md)

## Components in Markdown

Declare an HTML Next component in a page, or link one, and use it on the next line. Its controller is TypeScript.

## Versions

`markupress snapshot v1` records the docs as they stand. Readers switch versions and keep their place.

## Conventions first

Folders are sections, an index page labels its folder, and `_footer.md` is the footer. Configuration comes last.
