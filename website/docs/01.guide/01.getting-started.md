# Getting started

Markupress builds a versioned documentation site from Markdown, with native HTML Next components, MarkupKit routing and a Looma theme. It runs on Node 22.22.2 or later in Node 22, or Node 24.15 or later in Node 24.

## Create a site

`npm create markupress` starts a site in a new folder, with a home page, guide pages, a component and the configuration:

```sh
npm create markupress@latest docs
cd docs
npm install
npm run dev
```

The starter's `package.json` has `dev`, `build` and `preview` scripts, and depends on Markupress and the HTML Next and Looma releases it pins. Its files follow the [project structure](02.project-structure.md).

## Install

To add Markupress to an existing project, install it from npm as `markupress`:

```sh
npm install markupress
```

`@nextwebwg/html-next` and `@threadlabs/looma` are peer dependencies, so a site shares one copy of each with its own components. npm installs them with Markupress. Pages link Looma's components by package name, so a pnpm site adds both as its own dependencies:

```sh
pnpm add markupress @nextwebwg/html-next @threadlabs/looma
```

## Write a page

`docs/index.md` is a complete site:

```markdown
# My project

Welcome to the documentation.
```

## Serve and build

```sh
npx markupress dev       # serve docs/ with live reload
npx markupress build     # write the static site to site/
npx markupress preview   # serve the built site
```

The dev server reloads open pages after any edit, addition or deletion. `build` writes a static site, the production output, which any static host serves (see [Deploy](09.deploy.md)).

Markupress is a thin layer over MarkupKit: it translates Markdown and manages versions, and MarkupKit routes, orders, renders, watches and builds the pages.
