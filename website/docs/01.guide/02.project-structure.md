# Project structure

A site needs no configuration. `docs/index.md` is a complete site, and `markupress dev` serves it. Files in known places shape the rest:

::: table

- File: `docs/index.md`
  Is: The version home, which every version needs. A number prefix such as `01.index.md` is allowed.

- File: `docs/<folder>/index.md`
  Is: The folder's page and its metadata (see [Folders](04.navigation.md)). Each top-level folder with an index page is a section: a top navigation link with its own sidebar.

- File: `docs/404.md`
  Is: The not-found page.

- File: `docs/_footer.md`
  Is: The footer: a heading per column, a list of links under each, and a copyright paragraph.

- File: `public/logo.svg`, `public/logo-dark.svg`
  Is: The logo before the title, and its dark-theme version.

- File: `public/favicon.svg`
  Is: The site icon.

- File: `app/components/`
  Is: The site's own components, which a page links as `@/app/components/<name>.html` (see [Components](03.writing/06.components.md)).

- File: `app/layouts/default.html`
  Is: A layout that replaces the Markupress shell (see [Layouts](06.theme/03.layouts.md)).

- File: `app/layouts/home.html`
  Is: A layout that replaces the home layout (see [Home page](06.theme/02.home-page.md)).

- File: `markupkit.config.ts`
  Is: MarkupKit options and plugins.

- File: `versions/<id>/`
  Is: A recorded version, written by `markupress snapshot` (see [Versions](05.versions.md)).

:::

Pages and their front matter come next, and the configuration comes last: `markupress.config.ts`, or plain JSON data in `markupress.config.json`, for the title, the base path and a few more settings (see [Configuration](../02.reference/01.configuration.md)).

The `markupress` command and these APIs also load the site's `markupkit.config.ts` (or `.js`) with MarkupKit's `loadConfig`, and add `markupress()` after its plugins, so MarkupKit plugins and options compose with Markupress:

```ts
// markupkit.config.ts
import { defineConfig } from '@threadlabs/markupkit';
import { feed } from './plugins/feed.js';

export default defineConfig({ plugins: [feed()], redirects: { '/start/': '/guide/install/' } });
```

`base` and `outDir` from the Markupress configuration or the command line win over the MarkupKit config's; without either, they are `/` and `site`. `markupress()` includes the `markdown()` plugin, so the MarkupKit config lists neither.
