# Embeds

An embed is a component: a file in `app/components/` that takes the embed's ID as a typed prop and renders the provider's frame or card. A page links it and uses it like any other [component](06.components.md).

## A YouTube component

`app/components/youtube.html` renders a lazy-loaded YouTube frame from a video ID:

```html
<template component="x-youtube">
  <defs>
    <prop name="video" type="string" required>The video's ID, the part after watch?v= in a YouTube URL.</prop>
    <prop name="label" type="string" default="YouTube video">The frame's accessible title.</prop>
  </defs>
  <iframe from:src="concat('https://www.youtube-nocookie.com/embed/', $video)" from:title="$label"
    loading="lazy" referrerpolicy="strict-origin-when-cross-origin"
    allow="accelerometer; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
    allowfullscreen></iframe>
  <style>:host { display: block; inline-size: 100%; aspect-ratio: 16 / 9; margin-block: 1rem; border: 0; }</style>
</template>
```

- `video` is a required string prop, and `label` an optional one.
- `from:src` builds the frame's URL on `youtube-nocookie.com`, YouTube's privacy-enhanced mode.
- `from:title` gives the frame its accessible name from `label`, which a page sets to the video's title.
- `loading="lazy"` loads the frame as it nears the viewport.
- The frame is the template's one root element, so `:host` styles it.

## Using it in a page

Link the component once, then write the element on its own line:

```markdown
<link rel="component" href="@/app/components/youtube.html">

<x-youtube video="aqz-KE-bpKQ" label="Big Buck Bunny"></x-youtube>
```

## More embeds

Each dev.to Liquid tag is a component of the same shape: its arguments become props, and its template renders the provider's embed.

| dev.to tag | Component |
| --- | --- |
| `{% youtube aqz-KE-bpKQ %}` | `<x-youtube video="aqz-KE-bpKQ">`, a `youtube-nocookie.com/embed/` frame |
| `{% vimeo 76979871 %}` | `<x-vimeo video="76979871">`, a `player.vimeo.com/video/` frame |
| `{% codepen https://codepen.io/user/pen/abcde %}` | `<x-codepen user="user" pen="abcde" tab="result">`, a `codepen.io/user/embed/abcde` frame |
| `{% stackblitz project-id %}` | `<x-stackblitz project="project-id" file="index.ts">`, a `stackblitz.com/edit/project-id?embed=1` frame |
| `{% codesandbox sandbox-id %}` | `<x-codesandbox sandbox="sandbox-id">`, a `codesandbox.io/embed/` frame |
| `{% github owner/repo %}` | `<x-github repo="owner/repo">`, a card from a `<data>` request to `api.github.com/repos/owner/repo` |
| `{% gist https://gist.github.com/user/id %}` | `<x-gist gist="id" file="example.js">`, the file's text from a `<data>` request to `api.github.com/gists/id` |
