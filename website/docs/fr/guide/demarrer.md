# Commencer

Créez un site avec Node.js puis installez ses dépendances :

```sh
npm create markupress@latest mon-site
cd mon-site
npm install
npm run dev
```

Écrivez vos pages dans `docs/`. Le site prend en charge la recherche locale et les versions de documentation.
