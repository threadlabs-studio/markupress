# Command line

```sh
markupress dev        # serve the site with live reload
markupress build      # write the static site
markupress preview    # serve the built site
markupress snapshot <version-id>
```

`markupress` alone runs `dev`. Each command reads the site's [configuration](01.configuration.md) and its `markupkit.config.ts`.

::: table

- Command: `dev`
  Does: Serves the site from its sources, and reloads open pages after any edit, addition or deletion.

- Command: `build`
  Does: Writes the static site to `outDir` (`site` by default), checking every link, and prints the number of pages.

- Command: `preview`
  Does: Serves the built site from `outDir`.

- Command: `snapshot <version-id>`
  Does: Validates a build and records the current docs as the version `<version-id>` in `versions/<version-id>/` (see [Versions](../01.guide/05.versions.md)).

:::

::: table

- Flag: `--root <directory>`
  Does: The site's directory, in place of the current directory.

- Flag: `--base <path>`
  Does: The URL path the site is served under, such as `/docs/`, in place of the configured `base`.

- Flag: `--port <number>`
  Does: The port `dev` and `preview` listen on.

- Flag: `--help`, `-h`
  Does: Prints the usage.

:::
