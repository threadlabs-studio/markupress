# Code blocks

Fenced code stays literal. Markupress highlights supported languages with Shiki at build time, and each block has Copy and Wrap controls when JavaScript is available.

## Captions and highlighted lines

Put presentation attributes in the fence's attribute list:

````markdown
```ts {highlight="1,3-4" show-line-numbers title="app/pages/index.ts"}
const first = 1;
const second = 2;
const third = 3;
const fourth = 4;
```
````

- `title` supplies the caption.
- `highlight` selects comma-separated lines or inclusive ranges.
- `show-line-numbers` numbers the lines. Use `show-line-numbers=false` to override the site's `lineNumbers` setting for one block.

A title-only fence uses `{title="notes.txt"}` without a language. Unknown languages render as escaped plain text.

## Code from a file

Name a file with `src` and leave the fence empty. The block shows the file's code, so the page always matches the file:

````markdown
```html {src="@/examples/save-button.html" highlight="3"}
```
````

`src` is a path beside the page, such as `./save-button.html`, or from the project root with `@/`. `highlight` counts the file's lines, and the other fence attributes work as usual. A missing file fails the build, and `markupress dev` reloads the page when the file changes.

## Live examples

`::example` shows an HTML file working, followed by its code:

```markdown
::example[Save and cancel]{src="@/examples/save-button.html"}
```

::example[Save and cancel]{src="@/examples/save-button.html"}

The file's HTML renders as HTML written in the page does, components included. The file links its own components with `<link rel="component">`, and relative paths in it start from the file's folder. The label is the caption, and `highlight` and `show-line-numbers` apply to the code. To show other sources of the same example, put the example and fences that name the other files in adjacent tabs.

## Literal content

Braces, HTML tags and comments inside a fence are code. Markupress does not evaluate them or remove notation comments. To change highlighting, edit the fence's attributes.

## Tabbed examples

Put a fenced block inside each adjacent `::: tab [Label]` container. See [Markdown](03.markdown.md#tabs-and-code-examples) for the complete syntax.
