# Front matter

Front matter is a YAML mapping. Each field becomes MarkupKit page metadata or page data, and an unknown or mistyped field fails the build with the Markdown file's path, the field and the expected type.

::: table

- Field: `title`
  Type: string
  Effect: The document `<title>`, the navigation, breadcrumb and pager label (MarkupKit `mk:label`), and `page.title`. Defaults to the first heading, then the file name. On a folder's index page it labels the folder.

- Field: `description`
  Type: string
  Effect: `<meta name="description">`, and the page's line in its folder's generated index.

- Field: `order`
  Type: whole number
  Effect: The page's place among its folder's pages, in place of its file's number prefix (MarkupKit `mk:order`). On a folder's index page it places the whole folder, and on the version home it is an error.

- Field: `navigation`
  Type: `hidden`, `collapsed` or `overview`
  Effect: `hidden` leaves the page out of navigation and keeps its route (MarkupKit `mk:navigation`). On a folder's index page, `collapsed` starts the folder's sidebar group closed. `overview` makes a non-index page its containing route group's overview link, without repeating it among sub-links.

- Field: `id`
  Type: string
  Effect: The document identity across versions, independent of the file name and route.

- Field: `aliases`
  Type: list of route paths
  Effect: Further URLs serving the page, relative to its version (MarkupKit `mk:alias`).

- Field: `redirectFrom`
  Type: list of route paths
  Effect: Old URLs of the page, relative to its version, such as `/setup/`. Each one redirects to the page (MarkupKit `mk:redirect-from`): with status 308 in `dev` and `preview`, and as a redirect page at the old URL in a build.

- Field: `layout`
  Type: string or `false`
  Effect: An MarkupKit layout, `app/layouts/<name>.html`, in place of the site's layout for this page (MarkupKit `mk:layout`). `home` is Markupress's [home page](../06.theme/02.home-page.md). `false` renders the page with no layout.

- Field: `outline`
  Type: `false` or `[min, max]`
  Effect: The heading levels in the page's "On this page" outline, `[2, 3]` by default. `false` gives an empty outline.

- Field: `head`
  Type: mapping
  Effect: `meta` (name to content), `og` (Open Graph property without `og:`, to content) and `canonical` (a URL), rendered into the document head.

- Field: `lang`
  Type: language tag
  Effect: The page's language, its `<html lang>`, in place of the site's `lang` option.

- Field: `markdownSyntax`
  Type: `standard` or `compatible`
  Effect: How the page's Markdown reads, in place of the site's `markdownSyntax` option.

- Field: `previous`, `next`
  Type: `false` or mapping
  Effect: The pager's links to the pages before and after this one. `false` drops the link, and `{ label, href }` relabels or retargets it, with `href` written as a link in the page, such as `../install.md`.

- Field: `editLink`
  Type: URL or `false`
  Effect: The page's "Edit this page" URL, in place of the one the [`editLink` option](../04.navigation.md#edit-link-and-last-updated) gives. `false` shows none.

:::

```yaml
---
title: Installation
outline: [2, 4]
editLink: https://github.com/org/repo/edit/main/docs/01.guide/02.install.md
head:
  meta: { keywords: "install, setup" }
  og: { image: https://example.com/social.png, type: article }
  canonical: https://example.com/guide/install/
---
```
