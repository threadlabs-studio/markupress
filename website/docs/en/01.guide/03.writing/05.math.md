# Math

Write math in TeX notation. Single dollar signs hold inline math, and `$$` lines hold display math:

```md
The energy is $E = mc^2$.

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

The energy is $E = mc^2$.

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

Markupress typesets math as [MathML](https://developer.mozilla.org/en-US/docs/Web/MathML) when the site builds. Browsers render MathML natively, so pages load no math script or font. Each formula keeps its TeX as an annotation, which assistive technology and copy tools can read.

## Prices stay text

An opening `$` needs a non-space after it, and a closing `$` a non-space before it and no digit after it. Prose about money needs no escapes:

```md
Plans cost $5 and $10, or $5–$10 a month.
```

Write `\$` for a dollar sign that would otherwise pair with another, such as `\$x$`.

## Display math on one line, and captions

`$$x^2$$` alone on a line is display math too. A `math` fence, the form GitHub also reads, can carry a caption:

````md
```math {title="Euler's identity"}
e^{i\pi} + 1 = 0
```
````

```math {title="Euler's identity"}
e^{i\pi} + 1 = 0
```

## Errors

TeX that cannot be read fails the build, naming the page and the formula. Markupress reads the TeX that [Temml](https://temml.org/docs/en/supported) supports, which covers LaTeX math and the AMS environments.
