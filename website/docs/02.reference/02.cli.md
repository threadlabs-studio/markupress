# Command line

```sh
markupress dev        # serve the site with live reload
markupress build      # write the static site
markupress preview    # serve the built site
markupress snapshot <version-id>
```

`markupress` alone runs `dev`. Each command reads the site's [configuration](01.configuration.md) and its `htmlkit.config.ts`.

| Command | Does |
| --- | --- |
| `dev` | Serves the site from its sources, and reloads open pages after any edit, addition or deletion. |
| `build` | Writes the static site to `outDir` (`site` by default), checking every link, and prints the number of pages. |
| `preview` | Serves the built site from `outDir`. |
| `snapshot <version-id>` | Validates a build and records the current docs as the version `<version-id>` in `versions/<version-id>/` (see [Versions](../01.guide/05.versions.md)). |

| Flag | Does |
| --- | --- |
| `--root <directory>` | The site's directory, in place of the current directory. |
| `--base <path>` | The URL path the site is served under, such as `/docs/`, in place of the configured `base`. |
| `--port <number>` | The port `dev` and `preview` listen on. |
| `--help`, `-h` | Prints the usage. |
