# Markupress identity

The printer's monogram and wordmark preserve the silhouettes in [the approved reference](markupress-reference.png). Both are vector paths, including the lettering; the lockup has no font dependency or embedded raster image.

- `website/public/logo.svg` and `logo-dark.svg`: the complete lockup, with transparent backgrounds.
- `website/public/mark.svg`: the standalone monogram.
- `website/public/favicon.svg`: the same monogram with a dark-mode color treatment.

Large headings use Georgia through Looma's `--ui-font-display` property. Body text and controls use `--ui-font-sans`.
